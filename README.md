# Live Score Overlay

Transparentes Overlay mit Live-Spielständen.

Wettbewerbe: 1. Bundesliga, 2. Bundesliga, Champions League, DFB-Pokal

## Download
Unter "Releases" die Datei LiveScoreOverlay.exe herunterladen und starten.

Falls Windows warnt: "Weitere Informationen" und dann "Trotzdem ausführen".

Beenden: Rechtsklick auf die Leiste.

Inoffizielles Hobbyprojekt, nicht mit ESPN, UEFA, DFB oder DFL verbunden.
